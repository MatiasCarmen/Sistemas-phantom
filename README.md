# Sistemas Phantom

Sistema web para la gestion de inventario, cotizaciones y ventas orientado a pequenas empresas comerciales.

## Tecnologias

- React
- Vite
- TypeScript
- Express
- Node.js

## Instalacion

```bash
npm install
```

## Ejecucion local

```bash
npm run dev
```

La aplicacion se ejecuta por defecto en:

```text
http://localhost:8081
```

## Estado del proyecto

El frontend se encuentra preparado como primer avance visual. La integracion completa del backend y la base de datos en la nube se implementara en las siguientes etapas.
